调整原则

一句话：先告诉用户"现在该干嘛"，再告诉他"还要多久"。

1. 一张卡只有一个主数字大字显示"车离我还有几分钟"。其他信息都比它小。
2. 显示当前阶段追踪时标出"等车 / 乘车 / 换乘步行"，和新的两阶段追踪逻辑对应。
3. 不显示没用的数字第 2 程的车现在离换乘站多远，对用户没用。改为显示"预计换乘时间"，或者不显示。
4. 颜色全部用主题色去掉写死的 0xFF00875A 等颜色。成功、警告也做成主题颜色，深色模式能自动适配。
5. 好点、不挤点击区域至少 48dp。不常用的操作收进 ⋮ 菜单。线路胶囊放不下时自动换行。
6. 图标和文字不重复去掉 "■ 结束追踪"、"★ 存入收藏" 里多出来的文字符号。
