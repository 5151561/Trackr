0. v3 改了什么

乘车码悬浮按钮 v3

  • 「公交」页右下角固定一个按钮，写「乘车码」。
  • 往下滑时缩成只有图标，往上滑展开。
  • 点一下直接打开「我的」里选的平台。选了「每次询问」才弹选择。
  • 站点页、线路页、路线详情：按钮在底部操作栏最右边，位置不变。
  • 顶栏的乘车码图标删掉。通知和系统快捷方式照留。

一起等多条线 v3

  • 站点页点「一起等」，勾几条线，同时追踪。
  • 大字永远显示最先到的那辆，其他线排在下面。
  • 点「我上车了」：认定是此刻在站的那辆。两辆同时在站才问「上了哪辆」。
  • 路线详情里每程勾了的线都一起等，不再只等一条。
  • 站点页勾好的组合可以收藏，存成只有 1 程的路线。

代码现状：TrackingSessionState 和 BusTrackingService 一次只追一条线，TransferAutoSwitchManager 每程只取一条线。一起等要改追踪服务，同时拉多条线的实时数据。

1. 设计原则

一眼看到车

  • 每屏最大的字是「几分钟 / 几站」。
  • 没车时写下一班发车时间，不写空话。

一件事一个入口

  • 收藏只有一处：首页。
  • 设置只有一处：「我的」。
  • 不用长按藏功能。

一屏一个主按钮

  • 页面底部只有一个实心按钮。
  • 其他操作放顶栏或「⋮」。

说人话

  • 用「起点 → 终点」箭头。
  • 不用 emoji，不写营销语。
  • 同一个东西只用一个叫法。
