## 一、交互设计升级：极简化「线路号码胶囊切换器 (Line Badges)」

### 1. 痛点重塑
拒绝传统应用中“备选线路:”、“同站其他备选:”等冗余文本说教，回归极简出行本质：
- **符号化**：直接以 `[ 🚌 320 ]` `[ 🚌 M194 ]` `[ 🚌 311 ]` 纯线路号码胶囊并排呈现。
- **状态高亮**：系统默认高亮推荐**最先到站**的线路（外加小绿点或微标签 `1站`）；用户点击其他号码胶囊，卡片内容无缝平滑切换为该线路的实时动态。
- **无缝复用**：无论是「单段多线直达卡片」，还是「多段换乘卡片中的某一段」，全部统一采用该交互模式。

## 二、卡片信息结构规范 (UI Spec)

### 1. 多线同达卡片
```
+-----------------------------------------------------------------------+
| 🏠 家 ➔ 科技园                                                        |
| 深大北门 ➔ 高新园                                                     |
+-----------------------------------------------------------------------+
| [ 🚌 320 · 1站 🟢 ]*   [ 🚌 M194 · 4站 ]   [ 🚌 311 · 8站 ]    [ + ]  |
+-----------------------------------------------------------------------+
| ┌───────────────────────────────────────────────────────────────────┐ |
| │ 320 路 (开往 恒丰方向)                    还有 1 站 · 约 2 分钟   │ |
| │ 粤B·58921 · 舒适 · 乘 4 站即达             [ 点击查看实时轨迹 > ] │ |
| └───────────────────────────────────────────────────────────────────┘ |
+-----------------------------------------------------------------------+
```
*注：`*` 代表当前处于选中激活态的线路号码，点击 `M194` 立即切换下方为 M194 的到站信息。

### 2. 换乘时间轴卡片中的多线切换
```
  ├─ [第 1 程]  [ 320 ]*  [ M375 ]
  │   • 还有 2 站 · 约 4 分钟 (粤B12345) ➔ 目标下车: 高新园站
```
点击 `M375` 立即将第 1 程动态切换为 M375。
