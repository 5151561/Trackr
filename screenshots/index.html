【自制开源】给公交出行做了一款纯粹、优雅的实时到站追踪器 —— Trackr (BusOnRoad) 每次出门等公交，官方 App 广告多、臃肿卡顿？ 我花时间用 Jetpack Compose 和最新的 Material Design 3 Expressive 规范，重新做了一款干净、直观的实时公交追踪应用。 ✨ 核心亮点： 1. 【颜值即正义】完整遵循 Material 3 Expressive 规范，动态取色、悬浮胶囊工具栏、平滑弹簧动效，支持深浅模式。 2. 【全景走向双视图】首创横向全景滚动轨道 + 纵向时间轴视图自由切换，沿途车辆实时停靠区间一目了然。 3. 【实时车队雷达】一眼看清整条线路上所有在途车辆，车牌号、车速、舒适拥挤度、剩余站数全掌握。 4. 【常驻呼吸追踪】支持置顶呼吸动态卡片与通知栏常驻追踪，到站前自动震动提醒，从此不用反复掏手机看刷新。 5. 【纯粹无广告】代码开源，无开屏广告、无无意义推送，只做纯粹的交通工具。 欢迎尝鲜体验与提出建议，项目已在 GitHub 开源！
[分享] 用 Jetpack Compose + Navigation 3 写了一款 Material 3 Expressive 风格的实时公交追踪器 Trackr 各位 V 友，平时通勤坐公交，市面上主流实时公交 App 的广告和信息流越来越重，经常只是想看下一班车还有几分钟，却被开屏卡顿折磨。 于是我写了 Trackr (BusOnRoad)，目标是做一款极简、高响应、体验现代的通勤利器。 🛠 技术栈细节： - UI：100% Jetpack Compose，采用 Material 3 Expressive 规范（悬浮胶囊工具栏、弹簧物理动画） - 导航：全新 AndroidX Navigation 3 类型安全架构 - 异步：Kotlin Coroutines & StateFlow 响应式单向数据流 - 适配：支持 412dp+ 全机型自适应与 OLED 深色高对比模式 - 架构：清晰的 Domain / Repository / UI 分层 开源地址：https://github.com/5151561/Trackr- 欢迎 PR、Issue 和 Star！
